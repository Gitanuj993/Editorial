# LeetCode Question 1833 : Maximum Ice Cream Bars

## Problem Statemnet 

```txt
It is a sweltering summer day, and a boy wants to buy some ice cream bars.
At the store, there are n ice cream bars. You are given an array costs of length n,
where costs[i] is the price of the ith ice cream bar in coins.
The boy initially has coins coins to spend, and he wants to buy as many ice cream bars as possible. 
Note: The boy can buy the ice cream bars in any order.
Return the maximum number of ice cream bars the boy can buy with coins coins.
You must solve the problem by counting sort.
```
## Problem Description
```txt
a boy has some coins and want to purchase as many ice-cream as possible,
ice-creams are given of costs in integers in unsorted manner which emphasis he can only
buy icecreams untill he has coins to spend,
Our problem is to find out how many maximum numbers of ice-cream
he can buy with his coins ?
```

## Approach 1 : Without Counting sort , using sorting
> in python 

```txt
Time Complexity: O(n log n)
Auxiliary Space: O(1)
Including Python sort's internal memory: O(n)
```

```python
class Solution :
	def maxIceCream(self,costs,coins) :
		costs.sort()
		max_ice_creame = 0
		coins_spent = 0
		for i in costs :
			coins_spent += i
			if coins_spent <= coins :
				max_ice_creame += 1
			else :
				break
		return max_ice_creame

```

> in java
```java
import java.util.Arrays ;
class Solution {
    public int maxIceCream(int[] costs, int coins) {
        Arrays.sort(costs) ;
        int count = 0;
        for ( int i = 0 ; i < costs.length ; i++){
            int purchase = costs[i] ;
            if ( purchase <= coins) {
                count += 1 ;
                coins -= purchase ;
            }
            else {break ;}
            
        }
        return count ;
        
        
    }
}
```

        }
        return count ;
    
    }

## Approach 2 : With counting sort

```txt
Time Complexity : O(m+n)
Space Complexity : O(n)

```


> python 
```python
class Solution :
	def maxIceCream(self,costs, coins) :
		#purchase made
		purchase = 0		
		# number of icecreames purchased
		count = 0
		# using counting sort
		# creating counting sort array
		max_element = max(costs)
		#print(" max element : " , max_element)
		count_array = [0] * ( max_element + 1)
		#print(" count_array : " , count_array)
		
		# counting  counting sort
		for pos in costs :
			count_array[pos] += 1
		#print(" count_array : " , count_array)
			
		# lets solve the problem using counting sort		
		for index in range(len(count_array)) :				
			for _ in range(count_array[index]) :
				purchase += index
				if purchase <= coins :
					count += 1
				else :
					break 
		return count
```
